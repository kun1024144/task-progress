# task-progress（任務進度條）

在輸入框上方列出這個對話裡所有正在跑的子代理任務（前景或背景）：

```
任務進度 · 2 個進行中                     清除已完成
  整理作業檔案   ████████████░░░░░░░░░░░░ 50%  約剩 2 分鐘
  查 OS 講義     ████████████████████████ ✓ 完成
```

- 子代理本身不回報進度，所以百分比是**估計值**：依同類型任務過去的平均耗時計算（第一次預設 3 分鐘，之後自動學習），任務真正結束前最多顯示到 95%。
- 完成的任務變綠色 ✓，失敗則是紅色 ✗；完成 10 分鐘後自動移除，或按「清除已完成」。
- 點任務名稱，對話會捲回啟動那個任務的位置。

## 安裝

```
/plugin install task-progress --marketplace <owner>/<repo>
```
